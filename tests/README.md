# Directorio de Pruebas

Este directorio contiene datos de prueba para el proyecto Vocolore.

## Contenido

- `narrativas_nino.txt` - Textos narrativos reales de niños para pruebas de generación de imágenes
- `test_transcription.py` - Script de prueba para el pipeline de transcripción
- `clips/` - (Opcional) Clips de audio de prueba para transcripción

## Nota

Este directorio está en `.gitignore` y no se sube al repositorio por contener datos personales.
